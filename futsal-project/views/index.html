Sobre o Sistema

Este sistema foi desenvolvido para facilitar o gerenciamento completo de times de futsal, jogadores, técnicos e competições. Você pode cadastrar, editar e deletar informações de forma prática e eficiente.

Funcionalidades

  • ✓ CRUD completo de Técnicos
  • ✓ CRUD completo de Times
  • ✓ CRUD completo de Jogadores
  • ✓ CRUD completo de Competições
  • ✓ Associação de Jogadores a Times
  • ✓ Associação de Técnicos a Times
  • ✓ Banco de dados PostgreSQL
